Typefill

Type a shortcut anywhere and it turns into the full text. Press Ctrl+Shift+Space to find a snippet by name.

How to set up a snippet

  1. Click New snippet on the left, or click a snippet in the list to change it.
  2. In Shortcut, type what you will type to bring the snippet in, like /hello. Starting with / keeps it from going off in the middle of a normal word. No spaces.
  3. In Name, write what it is for, so you can find it later.
  4. In the big box at the bottom, write the text you want typed in.
  5. To have it ask you for something first, like a name, a date or a choice, click Text box, Date picker or Dropdown above the big box. They put the right code in for you, so you never have to type it.
  6. It saves by itself. You will see Saved at the bottom.
  7. Try it in the box below. Then type it anywhere: in email, chat, documents and nearly every text box on the web.

How fields work
  • {formtext: name=First name; default=Sam} a box to type in
  • {formmenu: name=Size; default=M; S; L} a dropdown, the default comes first
  • {formdate: name=Due; format=D MMMM; default=+7D} a date picker, a week from today here
  • {formtoggle: name=PS}...{endformtoggle} text you can tick on or off
  • {note}...{endnote} shown in the form but not typed out, like a dropdown that only steers an if
  • {=First name} repeats a field's answer
  • {import: /sig} puts another snippet in
  • {time: dddd D MMMM; shift=+1D} the date, tomorrow here
  • {clipboard} what you last copied, {cursor} where the caret ends up
